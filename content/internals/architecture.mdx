# Architecture

Understanding the internal structure of Tilemap Parser.

## Overview

Tilemap Parser is designed with simplicity and performance in mind. The architecture consists of several key components that work together to parse, validate, and expose tilemap data.

## Component structure

```
┌─────────────────────────────────────┐
│      TilemapParser (Public API)     │
├─────────────────────────────────────┤
│  Parser Layer (Input handling)      │
│  - File loading                     │
│  - String parsing                   │
│  - Dictionary conversion            │
├─────────────────────────────────────┤
│  Validation Layer                   │
│  - Schema validation                │
│  - Type checking                    │
│  - Data integrity                   │
├─────────────────────────────────────┤
│  Data Model Layer                   │
│  - MapData                          │
│  - Layer types                      │
│  - Tileset management               │
├─────────────────────────────────────┤
│  Utility Layer                      │
│  - Collision detection              │
│  - Property access                  │
│  - Coordinate conversion            │
└─────────────────────────────────────┘
```

## Parser layer

The parser layer handles input in multiple formats:

### File input

```python
def parse_file(filepath):
    with open(filepath) as f:
        data = json.load(f)
    return parse_dict(data)
```

Reads JSON files from disk and converts to dictionary.

### String input

```python
def parse_string(json_str):
    data = json.loads(json_str)
    return parse_dict(data)
```

Parses JSON strings directly.

### Dictionary input

```python
def parse_dict(data):
    # Validation happens here
    return MapData(data)
```

Core parsing logic that handles dictionaries.

## Data model

### Class hierarchy

```
Object (base)
├── MapData
│   ├── Layer (container)
│   │   ├── TileLayer
│   │   ├── ObjectLayer
│   │   └── ImageLayer
│   └── Tileset
│       └── Tile
```

### MapData

Top-level container for all map data:

- `width`, `height`: Map dimensions
- `tilewidth`, `tileheight`: Tile size
- `layers`: Collection of layers
- `tilesets`: Collection of tilesets
- `properties`: Custom metadata

### Layers

Layers organize map content:

**TileLayer**: Grid-based tile data with IDs

**ObjectLayer**: Contains objects with positions and properties

**ImageLayer**: References to background images

### Tilesets

Tilesets define visual and logical tile properties:

- `image`: Path to spritesheet
- `tiles`: Individual tile definitions
- `properties`: Per-tile attributes

## Performance considerations

### Lazy loading

Data is loaded on-demand:

```python
class MapData:
    def __init__(self, data):
        self._raw = data
        self._layers = None  # Loaded on first access
    
    @property
    def layers(self):
        if self._layers is None:
            self._layers = self._parse_layers()
        return self._layers
```

### Memory efficiency

Tile data uses compact storage:

```python
class TileLayer:
    def __init__(self, data):
        # Store as flat list for memory efficiency
        self.data = tuple(data['data'])
    
    def get_tile(self, x, y):
        # Calculate index from coordinates
        return self.data[y * self.width + x]
```

### Caching

Frequently accessed data is cached:

```python
class MapData:
    def __init__(self, data):
        self._tileset_cache = {}
    
    def get_tileset(self, name):
        if name not in self._tileset_cache:
            # Find and cache
            self._tileset_cache[name] = self._find_tileset(name)
        return self._tileset_cache[name]
```

## Error handling

Validation occurs at multiple levels:

### Schema validation

```python
def validate_schema(data):
    required_fields = ['width', 'height', 'tilewidth', 'tileheight']
    for field in required_fields:
        if field not in data:
            raise TilemapParserError(f"Missing required field: {field}")
```

### Type checking

```python
def validate_types(data):
    if not isinstance(data['width'], int):
        raise TilemapParserError("width must be an integer")
```

### Data integrity

```python
def validate_layer(layer_data):
    expected_size = layer_data['width'] * layer_data['height']
    actual_size = len(layer_data['data'])
    if actual_size != expected_size:
        raise TilemapParserError(
            f"Layer size mismatch: expected {expected_size}, got {actual_size}"
        )
```

## Extension points

### Custom validators

Add custom validation logic:

```python
class CustomParser(TilemapParser):
    def validate(self, data):
        super().validate(data)
        # Additional validation
```

### Custom properties

Access and manipulate custom properties:

```python
map_data = parser.parse_file('map.json')
if 'difficulty' in map_data.properties:
    difficulty = map_data.properties['difficulty']
```

### Custom layers

Handle custom layer types:

```python
for layer in map_data.layers:
    if layer.type == 'custom_layer':
        # Handle custom layer
        pass
```
